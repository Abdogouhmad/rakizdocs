🚀 Rakiz 0.4.3 Release

Good morning Android users 👋

Version **0.4.3** is now available, introducing a new productivity enhancement while maintaining the UI and structural improvements from previous releases.
<!--truncate-->

## ✨ What’s New

### 🔕 Do Not Disturb Mode (NEW)
- Rakiz now activates **Do Not Disturb mode** during Focus sessions.
- Helps eliminate distractions while the timer is running.
- Automatically aligns with productivity workflow.
- Designed to improve deep focus experience.

---

## 🔄 Dynamic App Bar
- The AppBar updates dynamically based on the active session:
  - **Focus**
  - **Short Break**
  - **Long Break**
- Improves visual feedback and session awareness.

---

## 🛠 Improvements

- **Timer Typography Adjusted**
  - Font size optimized to properly fit inside the circular layout.
  - Prevents overflow on smaller screen sizes.

- **Settings AppBar Alignment**
  - Title alignment moved from `center` to `start` (left-aligned).
  - Improves readability and follows Material Design conventions.

- **Timer Settings Refactored**
  - Timer duration configuration moved from the Home screen to **Settings → Timer**.
  - Provides better organization and cleaner Home UI.
  - Improves scalability for upcoming feature expansions.

---

## ⚠️ Known Limitations

> The following features are currently **UI-present but not fully functional**:

- Short Break duration customization
- Long Break duration customization
- Session length
- Timer settings logic (partially implemented)

Currently, only the following are fully functional:
- ✅ Focus set duration  
- ✅ Do Not Disturb activation during Focus

These features are staged for full backend logic implementation in upcoming releases.

---

:::note

This release focuses on:
- Enhancing focus experience with Do Not Disturb mode
- Maintaining UI consistency
- Continuing structural refactoring
- Preparing the architecture for future feature activation

More updates will be rolled out progressively.
:::
