🚀 Rakiz 0.4.1 Release

Good morning Android users 👋

Version **0.4.1** is now available, bringing UI refinements and structural improvements to enhance usability and future scalability.
<!--truncate-->

## ✨ What’s New

### 🔄 Dynamic App Bar
- The AppBar now updates dynamically based on the active session:
  - **Focus**
  - **Short Break**
  - **Long Break**
- Improves visual feedback and session awareness.

---

## 🛠 Improvements

- **Timer Typography Adjusted**
  - Reduced font size to ensure proper fitting inside the circular layout.
  - Prevents overflow on smaller screen sizes.

- **Settings AppBar Alignment**
  - Title alignment moved from `center` to `start` (left-aligned).
  - Improves readability and follows Material Design conventions.

- **Timer Settings Refactored**
  - Timer duration configuration moved from the Home screen to **Settings → Timer**.
  - Provides better organization and cleaner Home UI.
  - Improves scalability for upcoming feature expansions.

---

## ⚠️ Known Limitations

> The following features are currently **UI-present but not fully functional**:

- Short Break duration customization
- Long Break duration customization
- Session length
- Timer settings logic (partially implemented)

Currently, only the following are fully functional:
- ✅ Focus set duration

These features are staged for backend logic implementation in upcoming releases.
